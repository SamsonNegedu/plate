## How these stay accurate

- `api.md` is generated by `make generate` from the OpenAPI spec, and `make verify` fails if it is stale.
- A Go test (`internal/docscheck`) fails when a table in `db/migrations` is missing from `data-model.md`, an environment variable in the code is missing from `configuration.md`, an endpoint is missing from `api.md`, or a relative link in these docs is broken.
- Everything else is prose. When you change behavior a document describes, change the document in the same commit.
